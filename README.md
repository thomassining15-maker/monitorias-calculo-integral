## 🧭 Cómo estudiar con este material

1. **Empieza por el tema:** busca el taller en `material-de-estudio/` y resuélvelo sin mirar la solución.
2. **Repasa con las guías:** `guias-y-repasos/` resume los conceptos y trae ejercicios explicados.
3. **Practica como en el examen:** resuelve un parcial de `parciales/` con tiempo limitado.
4. **Prepárate para el parcial:** usa los talleres de `talleres/` como simulacro final.

## ⚠️ Nota

Los parciales pertenecen a la Universidad Pontificia Bolivariana y se comparten solo con fines de estudio. El material de mi autoría (talleres, guías y repasos) puede usarse libremente para aprender. Los ejercicios de series siguen el libro *Cálculo*, de J. Stewart, que no se incluye en este repositorio.

Si encuentras un error en alguna solución, abre un [issue](../../issues) o escríbeme.
